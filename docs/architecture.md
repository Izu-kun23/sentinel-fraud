# Architecture decisions

## Keep the application executable without cloud infrastructure

Scikit-learn pipelines · XGBoost · SHAP · FastAPI · pandas. FastAPI serves the interface and API from one origin. SQLite is intentional for the single-user local portfolio scope; PostgreSQL and distributed workers are future scaling decisions rather than unused dependencies.

## Separate core logic from delivery

Domain algorithms and schemas do not depend on HTTP request objects. Services coordinate work. Provider and storage concerns live in infrastructure modules. Main is the composition root.

## Reproducibility before complexity

Seeded datasets and fixed corpora make notebooks and regression checks deterministic. No claimed result is generated by a UI placeholder.

## Explicit deployment scope

Training runs lazily on first access and is deterministic; each worker keeps its own in-memory models. A first request is slower. No serialized untrusted model is loaded. Scores are uncalibrated model estimates trained on synthetic data, not validated real-world fraud probabilities. No financial decisions should be automated from this demo. SHAP describes model behaviour, not causation. A real deployment requires licensed data, chronological/customer-group splits, calibration, fairness checks and drift monitoring.
